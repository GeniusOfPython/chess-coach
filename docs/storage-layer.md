# Storage layer

В проект добавлен единый слой `src/platform/appStorage.ts`.

Зачем он нужен:

- браузерная версия продолжает использовать `localStorage`;
- при ошибках доступа к `localStorage` приложение не падает, а использует временную память;
- в будущей Android/iOS-сборке этот слой можно заменить на Capacitor Preferences или другое native-хранилище;
- `App.tsx` больше не обращается к `window.localStorage` напрямую.

Что сейчас хранится через этот слой:

- режим игры;
- сторона игрока;
- уровень бота;
- активная рабочая область;
- настройки интерфейса;
- текущая PGN-партия;
- будущие настройки монетизации и согласия.

Следующий шаг для native-версии: сделать асинхронную реализацию поверх Capacitor Preferences, если понадобится синхронизация между web и mobile shell.
