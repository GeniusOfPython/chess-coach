# Smoke E2E: основной учебный цикл

Playwright проверяет критический путь продукта в Chromium:

1. Импорт готовой партии через PGN.
2. Запуск обзора партии.
3. Обнаружение ключевого переломного момента.
4. Переход из обзора к тренировочной позиции.
5. Выполнение правильного хода на реальной доске.
6. Фиксация исправления и обновление учебного прогресса.

Тест использует настоящий интерфейс приложения и детерминированный Worker-стаб
шахматного движка. Внешний ИИ, сеть и фактическая скорость Stockfish не влияют
на результат.

Первый запуск после установки зависимостей:

```bash
npm run test:e2e:install
npm run test:e2e
```

Повторные запуски:

```bash
npm run test:e2e
```

Обычный локальный запуск использует dev-сервер. Полный релизный gate сначала
собирает приложение, проверяет `dist`, затем запускает тот же сценарий через
production preview:

```bash
npm run check:ci
```

При падении Playwright сохраняет трассировку и снимок экрана в `test-results`.
