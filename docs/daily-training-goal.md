# Daily training goal

The best-move training panel now tracks a lightweight daily goal.

Current behavior:
- Daily target: 5 solved best-move tasks.
- The counter is stored locally.
- The counter resets automatically when the date changes.
- It does not add a new panel; it is embedded into the existing training card.

Future mobile use:
- Can be connected to push reminders.
- Can feed streaks and achievements.
- Can be synced to cloud accounts later.
