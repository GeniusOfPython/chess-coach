# Серии в тренировке лучшего хода

Добавлен лёгкий слой удержания без перегруза интерфейса:

- текущая серия лучших ходов подряд;
- лучший рекорд;
- общая точность тренировки;
- мягкая похвала при серии от 3 решений подряд.

Статистика хранится локально через `appStorage`. В будущей мобильной версии этот слой можно синхронизировать с аккаунтом или использовать для достижений.

Важно: серия не должна превращать тренер в казино-механику. Она нужна только для мягкой мотивации и отслеживания прогресса.
