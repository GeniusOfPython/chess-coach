# Автосохранение сессии

В браузерной версии текущая партия автоматически сохраняется в `localStorage` как PGN.

Ключ: `chess-coach.current-pgn`

При открытии приложения хук `useChessGame` пробует загрузить сохранённый PGN. Если PGN повреждён или отсутствует, создаётся обычная новая партия.

Зачем это нужно:

- пользователь не теряет партию при обновлении страницы;
- мобильная версия через Capacitor сможет использовать тот же принцип;
- позже можно заменить `localStorage` на Storage API, SQLite или облачную синхронизацию.

Пока сохраняется только сама партия. Настройки интерфейса уже сохраняются отдельными ключами.
