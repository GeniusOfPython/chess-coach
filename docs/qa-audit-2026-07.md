## Итог

Функциональное ядро проходит статическую проверку, 103 unit-теста и production-сборку. Архив в исходном виде не являлся воспроизводимой поставкой: отсутствовали TypeScript/Vite-конфигурации, а `dist/sw.js` ссылался на CSS и JavaScript предыдущей сборки. Оба блокирующих дефекта исправлены.

## Исправленные блокеры

### QA-001: архив не собирался

Отсутствовали:

- `tsconfig.json`;
- `tsconfig.app.json`;
- `tsconfig.node.json`;
- `tsconfig.server.json`;
- `vite.config.ts`.

Следствие: `npm run check` завершался ошибкой TS5083 до production-сборки.

### QA-002: offline использовал старые стили и JavaScript

Service worker в `dist` содержал старые хешированные имена ресурсов. Обычная команда сборки завершалась успешно и не обнаруживала рассогласование.

Исправление:

- шаблон SW вынесен из `public`;
- worker генерируется из фактического output bundle;
- версия зависит от содержимого текущей сборки;
- старый `dist/sw.js` удаляется перед генерацией;
- добавлены 3 регрессионных теста генератора;
- добавлен `scripts/verify-build.mjs`;
- CI отдельно проверяет все PWA-артефакты после сборки.

## Открытые риски

### P0 — до публикации

1. Вернуть и хранить `package-lock.json` в Git. Без него `npm ci` в CI не работает, а версии зависимостей не воспроизводятся.
2. Добавить Playwright E2E для Chrome, Safari/WebKit и мобильных viewport.
3. Добавить автоматический offline-тест: первая загрузка, активация SW, отключение сети, повторный запуск, проверка CSS/WASM.
4. Добавить axe-core и тест клавиатурной навигации.
5. Исключать `.env.local` из ручных ZIP-сборок, даже когда ключ пустой.

### P1 — инженерная устойчивость

1. `App.tsx` содержит около 1057 строк и координирует игру, движок, архив, достижения, workspace и UI. Следующая декомпозиция должна выделить `GameScreen`, `GameSetup`, `PostGameWorkspace` и orchestration-hook.
2. В проекте остаётся около 297 жёстко заданных CSS-цветов. Новый слой токенов уже создан, но компоненты нужно последовательно перевести на семантические роли.
3. Нет DOM/component-тестов React. Unit-тесты не обнаруживают потерянные кнопки, переполнение текста и ошибки ARIA-связей.
4. Основной JavaScript-бандл — около 423 КБ, 128 КБ gzip. Нужна ленивая загрузка архива, настроек, расширенного разбора и ИИ-панелей.
5. Полный `dist` занимает около 7.8 МБ главным образом из-за Stockfish WASM. Для PWA нужно отдельно проверить установку при медленной сети и ограниченной квоте хранилища.

### P2 — перед онлайн-режимом

1. Сервер должен быть единственным источником состояния рейтинговой партии.
2. Нужны авторизация, reconnect, идемпотентность ходов, часы на сервере и журнал событий.
3. Любые подсказки, анализ и assisted-флаги должны быть технически недоступны в рейтинговом матче.
4. Нужны нагрузочные, сетевые, антифрод- и security-тесты.
