# ADR-0008: Приватная диагностика и восстановление локальных данных

- Статус: Принято
- Дата: 2026-07-22

## Контекст

Белый экран и повреждённое локальное состояние недопустимы для Web/PWA и
будущих Capacitor-сборок. В то же время диагностический канал не должен
превращаться в скрытый сбор шахматных партий и пользовательских данных.

## Решение

- React Error Boundary, ошибки окна и необработанные Promise используют единый
  версионированный контракт отчёта.
- В отчёт входят тип, категория, обезличенный стек и код. Сообщение ошибки,
  PGN, FEN, ходы, состояние интерфейса, URL, user agent и значения storage
  запрещены.
- По умолчанию провайдер отсутствует и сетевой запрос не выполняется.
- Последние 20 обезличенных отчётов существуют только в памяти текущего запуска.
- Sentry или Crashlytics подключаются только через `configureCrashReporter`.
- Перед рендером известные локальные ключи валидируются. Удаляются только
  повреждённые записи с префиксом `chess-coach.*`; неизвестные будущие ключи,
  исправные записи и данные других приложений сохраняются.
- Ошибка диагностического провайдера никогда не влияет на приложение.

## Последствия

Новая диагностическая метаинформация требует изменения контракта и отдельного
теста на отсутствие пользовательских данных. Изменение схемы storage требует
добавления валидатора или миграции до включения ключа в предзагрузочную проверку.
