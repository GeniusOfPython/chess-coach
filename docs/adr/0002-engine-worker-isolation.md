# ADR-0002: Изоляция шахматного движка

- Статус: Принято
- Дата: 2026-07-21

## Контекст

Длительный расчёт Stockfish способен блокировать интерфейс, смешивать ответы разных запросов и оставлять незавершённые операции после смены партии.

## Решение

- Движок выполняется через отдельный Worker и не вызывается из компонентов напрямую.
- Владение Worker, очередь команд, тайм-ауты и завершение запросов сосредоточены в сервисе движка.
- Обычный анализ, ход бота и длительный обзор имеют различимые жизненные циклы.
- Потребители получают типизированный `EngineAnalysis`, а не сырой текст протокола UCI.
- Отмена или смена позиции делает запоздалый результат недействительным.

## Последствия

UI не знает о командах UCI. Замена движка или Worker-реализации не должна менять компоненты и предметные правила разбора.
