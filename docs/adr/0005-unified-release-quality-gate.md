# ADR 0005: единый релизный quality gate

- Статус: принято
- Дата: 2026-07-21

## Контекст

Архитектурная проверка, тесты, factual eval, сборка, проверка PWA и E2E ранее
запускались отдельными командами. Частичный зелёный результат можно было принять
за готовность проекта, а smoke-E2E проверял dev-сервер вместо собранного
production-артефакта.

## Решение

Локальный `npm run check` последовательно выполняет все проверки без браузера.
`npm run check:ci` добавляет smoke-E2E против production preview. Оркестратор
останавливается на первой ошибке и сохраняет машиночитаемый отчёт. CI публикует
`dist` только после полного успеха и сохраняет диагностику при падении.

## Последствия

- один итоговый статус соответствует реальной готовности релизного среза;
- factual eval нельзя случайно пропустить;
- E2E проверяет содержимое production-сборки;
- локальная проверка остаётся доступной без браузерного бинарника;
- полный gate дольше отдельных проверок, но его результат однозначен.
