# ADR-0004: Приватная продуктовая аналитика

- Статус: Принято
- Дата: 2026-07-21

## Контекст

Для оценки учебного цикла нужны продуктовые события, но шахматная партия, позиция и текст ИИ могут быть пользовательскими данными и не требуются для агрегированных метрик.

## Решение

- События имеют фиксированные имена, версию схемы и исчерпывающий набор примитивных свойств.
- Запрещены FEN, PGN, конкретные ходы, текст объяснения и идентификатор партии.
- По умолчанию провайдер отсутствует, поэтому локальная разработка ничего не отправляет.
- Ошибка будущего провайдера не влияет на партию, разбор или тренировку.
- Подключение внешней системы выполняется через один адаптер без импортов SDK в предметные модули.

## Последствия

Новая метрика добавляется через версионированный контракт и тест безопасности полей. Сырые шахматные данные не должны использоваться как быстрый способ упростить аналитику.
