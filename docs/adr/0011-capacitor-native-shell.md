# ADR 0011: Нативная оболочка Capacitor

## Решение

Web/PWA остаётся основной реализацией продукта. Android и iOS собираются из той
же production-версии через Capacitor 8. Нативные возможности доступны только
через модули `src/platform`; game, analysis и AI layers не импортируют SDK.

## Причины

- не создавать вторую реализацию шахматного и учебного цикла;
- сохранять одинаковые правила Free/Premium на всех клиентах;
- тестировать основную логику быстрыми web/unit/E2E-проверками;
- изолировать lifecycle, Back, Haptics, Share и будущие покупки.

## Следствия

- `android/` и `ios/` являются версионируемым исходным кодом;
- `dist` и скопированные WebView-ресурсы не версионируются;
- каждое изменение plugin/config проходит `npm run mobile:sync`;
- store receipts и entitlement не считаются доверенными без серверной проверки;
- публикация требует отдельного device и store-sandbox gate.
