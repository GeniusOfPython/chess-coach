# ADR 0010: проверяемое право доступа и адаптер покупок

Статус: Принято  
Дата: 22 июля 2026 года

## Контекст

Ранний прототип хранил `free/premium` как обычную настройку и позволял менять
её кнопкой. Такое состояние нельзя использовать как основание для доступа:
оно выдаёт Premium без покупки, не учитывает срок подписки и смешивает
пользовательские предпочтения с коммерческим правом.

## Решение

- право доступа хранится отдельным версионированным `EntitlementSnapshot`;
- безопасное состояние по умолчанию — `free`;
- поддерживаются постоянный `premium` и ограниченный по сроку `temporary`;
- истёкшее, неполное или повреждённое право автоматически даёт только Free;
- UI не может напрямую изменить тариф;
- магазин подключается только через `PurchaseProvider`;
- восстановление покупок обновляет единое право доступа;
- локальная копия нужна для офлайн-UX, но серверные функции обязаны повторно
  проверять право и квоты на сервере;
- рекламное согласие остаётся отдельным от права Premium.

## Последствия

Старый ключ `chess-coach.subscription-tier` сохраняется только для совместимости
проверки старых данных и не предоставляет доступ. E2E получает Premium через
единый тестовый entitlement в `e2e/testHarness.ts`.

Реальные StoreKit, Google Play Billing или RevenueCat подключаются адаптером,
не импортируются в React-компоненты и не меняют шахматный домен.
