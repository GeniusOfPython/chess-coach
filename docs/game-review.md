# Game Review

Крупный учебный этап: обзор партии анализирует до 24 последних полуходов и выделяет ключевые ошибки.

## Как работает

1. Для каждого хода берётся FEN до хода.
2. Stockfish считает лучший ход в этой позиции.
3. Сыгранный ход сравнивается с лучшим.
4. Позиция после хода оценивается повторно.
5. Потеря оценки превращается в вердикт: хороший ход, неточность, ошибка, грубая ошибка.

## Почему лимит 24 полухода

Полный анализ длинной партии может занять много времени, особенно на телефоне. Лимит защищает мобильные устройства от перегрева и зависаний.

## Следующие шаги

- добавить переход к найденной ошибке на доске;
- добавить тренировку по ошибкам из обзора;
- позже подключить нейросеть для человеческого объяснения ключевых моментов.
