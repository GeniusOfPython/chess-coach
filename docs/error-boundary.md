# Error Boundary

Добавлен верхнеуровневый React Error Boundary.

Зачем нужен:

- не показывать пользователю белый экран при ошибке;
- дать кнопку перезагрузки;
- дать безопасный сброс локальных данных приложения;
- упростить будущую диагностику Android/iOS-сборки.

Сейчас ошибки логируются в `console.error`. В будущем сюда можно подключить Sentry, Firebase Crashlytics или другой crash-reporting слой через `nativeBridge`.
