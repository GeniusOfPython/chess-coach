# Error Boundary

Добавлен верхнеуровневый React Error Boundary.

Зачем нужен:

- не показывать пользователю белый экран при ошибке;
- дать кнопку перезагрузки;
- дать безопасный сброс локальных данных приложения;
- упростить будущую диагностику Android/iOS-сборки.

Error Boundary передаёт сбой в приватный диагностический контракт и показывает
пользователю только код отчёта. Исходное сообщение ошибки, PGN, FEN, ходы,
состояние приложения и значения хранилища в отчёт не включаются.

Глобальные ошибки окна и необработанные Promise также проходят через этот
контракт. До 20 обезличенных отчётов хранятся только в памяти текущего запуска.
По умолчанию внешний провайдер отсутствует, поэтому приложение ничего не
отправляет. Sentry или Firebase Crashlytics подключаются одним адаптером
`configureCrashReporter`, без импорта SDK в компоненты и предметные модули.

Перед запуском интерфейса проверяются известные ключи `chess-coach.*`.
Повреждённые записи удаляются точечно, исправные данные и ключи других приложений
сохраняются. Пользователь получает краткое уведомление о восстановлении.
