# Mobile bottom navigation

The workspace switcher is prepared for native Android/iOS usage.

On desktop it stays as a regular card in the side panel.
On narrow screens it becomes a fixed bottom navigation bar with safe-area support.

This keeps the main learning flow reachable with one thumb:

- Учёба — coach plan, analysis, best-move training.
- Партия — game state, review, material, evaluation.
- Ещё — tools, history, PGN/FEN, settings.

When Capacitor is connected later, the same structure can remain unchanged.
