# AI Coach factual evaluation

Автоматический eval-набор является отдельным релизным воротом ИИ-тренера. Он
не вызывает внешний API и не расходует пользовательскую квоту.

## Что измеряется

- принятие корректных ответов, связанных с проверенными шахматными фактами;
- блокировка координатных ходов, которых нет в рассчитанных вариантах;
- отклонение неизвестных фактов и вариантов;
- обязательная связь объяснения с проверенным лучшим ходом;
- соблюдение структурированного контракта ответа;
- одинаковая работа для белых и чёрных, дебюта и эндшпиля.

Команда запуска:

```bash
npm run eval:ai-coach
```

Релиз блокируется, если хотя бы один критический кейс не пройден. Отчёт выводит
общую точность, точность grounding, долю заблокированных галлюцинаций, точность
ссылок на варианты и соответствие схеме отдельно.

## Расширение набора

Новые позиции и ответы добавляются в
`src/ai/evaluation/aiCoachEvalCases.ts`. Каждый кейс должен иметь уникальный
идентификатор, ожидаемый результат и категорию риска. Реальный ответ новой
версии модели сначала добавляется как кандидат, затем для него фиксируется
ожидаемое решение после шахматной проверки.

Этот набор проверяет формализуемую фактическую безопасность, но не заменяет
экспертную оценку ясности, полезности и естественности текста. Перед сменой
модели или промпта нужна отдельная выборочная проверка шахматистом.
